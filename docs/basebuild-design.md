# 中核を固定して基盤を選ぶ（最小版、2026-11-13）

置き場: `dmsim/discovery/basebuild.py`（S5）。評価は窓口 `dmsim.eval.api.measure_assembly`（`eval.assemble.run_one` の薄い包み、通常開幕・FAIR）を通す。実行は `tools/basebuild.py`（結果 data/discovery/basebuild/、デッキ data/decks/basebuild_<名前>.yaml）。既定の挙動と日次の経路は変えない（どこからも自動では呼ばない）。

## 仕組み
- 中核: data/known_combos/combos.yaml の parts の role: core を各4枚。ID の無い中核があれば data/registry/candidates.yaml の core。
- 基盤の候補: 実カード（試験札 T/R/L 番台を除く）を `deckplan.pool.classify` の役割（search・draw・prep=墓地肥やし・accel=マナ加速）で分ける。中核の文明に収まり、コスト4以下で、中核でない札を、役割ごとにコストの軽い順（同コストは ID 順）で3種まで。カード名の手書きリストは使わない。
- チャージ用の札: 役割も能力も持たないクリーチャーのうち、中核の文明ごとにコストの最も軽い1種。中核で埋まらない枠を4枚ずつで埋める。
- 貪欲: 候補1種4枚をチャージ用の札4枚と入れ替えたデッキを全部測り、点が最も上がった1種を採る。上がらなくなるか枠が尽きたら止める。点 = 入口到達の局数×3 + 揃った局数 + 揃ったターンの早さ。勝敗と V は使わない。選ぶ途中の測定は軽い設定（予算20・決定化1・上限6ターン・20局）。
- **承認済みに絞っていない**: 承認台帳を通る実カードは今1枚（オルゼキア）だけなので、実カード全体から選び、選んだ札の承認状況を結果 JSON の approval に残した（全部 未承認）。

## 結果（通常開幕40局、標準設定 予算200・決定化8・上限6ターン、相手は無抵抗）
| デッキ | 揃う | 3ターン目まで | 4ターン目まで | 入口到達 | 段2（macro 有効） |
|---|---|---|---|---|---|
| サガ 現行 | 11/40 | 2 | 3 | 0/40 | 0/40 |
| サガ 選択 | **22/40** | **9** | **19** | 0/40 | 0/40 |
| アカシック 現行 | 3/40 | 1 | 1 | 0/40 | 0/40 |
| アカシック 選択 | **14/40** | 2 | 2 | 0/40 | 0/40 |
macro の有無で数字は変わらない（入口に届かないので手が使われない）。
- 選ばれた基盤: サガ = 霊淵 アガルーム＝プルーフ（墓地肥やし、1コスト）、戦攻のシダン アカダシ（ドロー、1）、ブラッディ・クロス（墓地肥やし、1）、ザババン・ジョーカーズ（ドロー、1）。アカシック = ブラッディ・クロス、アガルーム（墓地肥やし）、シークレット・クロックタワー（サーチ、2）。序盤（コスト1〜2）の墓地肥やしは仕組みが自分で選んだ。
- 足りないもの: マナ加速が選ばれていない。サガの候補にある加速はコスト4の1種だけ（中核の文明＝水・闇に収まる加速が少ない）。アカシックは中核7種28枚で枠が12枚しかなく、3種で尽きた。入口（サガ: シャコガイル場・墓地のクリーチャー数、アカシック: アカシック3 が場）に届かないのは、経路（ドラゲリオン・森夢龍の踏み倒し）が揃う以上の手順を要するため。
- 注意: 選択デッキは中核を各4枚にしたので、現行デッキ（中核の枚数が違う）との差には枚数の差も含まれる。チャージ用の札にはカードデータ上で効果が空の呪文（ファントム・ベール等）が混ざる（データの欠けの可能性）。

## ドリル（holdout）への1回だけの適用
設定を変えずに `tools/basebuild.py build drill_lock` を回した（入口 data/loops/entry/drill_lock.json は成立局面と同じ条件で、適用の前に作った）。選ばれた基盤: ロウゴク童子・クミタテ・チュリス・借魂・冒険の翼 アドベンチュオ（点 4.00 → 32.29、軽い設定20局）。
登録の検証（候補 drill_lock_basebuild、成立局面は drill_lock と同じ形でデッキだけ差し替え、方針は札の名前に依らない形「コンボ以外をチャージ・捨てる」）: **段階0 0/8、段階1 0/8**。全局「相手の資源が増えた」で、自分の3〜11ターン目に破れた（自分の山札は19〜26枚残り）。破れ方は実デッキ版と同じ（ドリルが自分のマナも削る）。結果を見て仕組みは直していない。
