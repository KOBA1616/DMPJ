# カードの絞り込み基準（案）

全カードを LLM 変換・人の確認に回すのは費用も手間も大きい。変換の前に、原文の文字列だけで足切りする。
実装は `tools/select_cards.py`。基準の値はそこの表（ZONE_MOVES / PEAKY / DEMERIT / PLAIN）を直せば変わる。

## 目的との対応

探したいのは「ゾーン間移動を補完し合い、人間が見つけていないループ・ロックを作れる組み合わせ」。
そのため、効果が1つの動きで完結する凡庸なカードは外し、次を持つカードを残す。

## 除外する（凡庸）

- 能力がキーワードだけ、またはバニラ（ブロッカー、W・ブレイカー、S・トリガーなど。括弧書きの注釈は無視）
- 効果が次の1行だけ: 単純なドロー、クリーチャー1体の除去（破壊・バウンス・タップ）、
  山札の上からマナに置くだけの加速、パワー修整だけ

## 点数を付ける（足切りは既定 3 点）

| 観点 | 例 | 点 |
|---|---|---|
| ゾーン間移動の種類（墓地へ送る/墓地から戻す/マナ/シールド/山札/手札に戻す/踏み倒し） | 種類ごとに | 1〜2 |
| 複数のゾーンをつなぐ | 2種類以上で（種類数−1） | +1〜 |
| 自己再利用 | 「このクリーチャーが墓地から…」 | 2 |
| 置換 | 「かわりに」 | 2 |
| ターン操作 | 追加ターン | 3 |
| 勝敗・山札切れ | 「ゲームに負ける」「山札がない」 | 3 |
| 回数を稼ぐ・大量処理 | 「好きな数」「すべて」 | 1 |
| 誘発の連鎖 | 出た時・破壊された時・ターン終了時 | 1 |
| デメリット付き | 「できない」自損、自分のカードを失う | 1〜2 |

デメリット付きの強力効果とピーキーな効果を高く評価する（決定事項）。凡庸でも複数ゾーンをつなぐ呪文
（マナ加速＋墓地肥やしなど）は 3 点に届くので残る。

## 限界と運用

- 文字列の一致なので、原文の言い回し違いで取りこぼす／拾いすぎることがある。拾いすぎは変換後の確認で落ち、
  取りこぼしは `--excluded` で除外理由を見て基準を直す。
- 点数は「変換する価値」の目安で、コンボの強さではない。強さは1人回し（`dmsim.solitaire`）で測る。
- 手順: fetch → `select_cards.py --ids` → convert（残りは `--min-score` を下げて後から）→ `report_gaps.py` で不足語彙を確認。
