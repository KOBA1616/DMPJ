## 決定事項
- 日本語でやり取りする。リポジトリは非公開。ルールは公式総合ルール最新版（Ver.1.53）。
- フォーマットはオリジナル。強いコンボ＝高確率で3〜4ターン目にループキルまたはプレイヤー撃破。
- カードテキスト→効果データは LLM 変換＋人の確認（`source.review`）。DMP の調整・テキストは使わない。
- 乱数シードと対戦ログで再現性を担保。拡張性重視（Python＋効果をデータ記述、後でコア Rust 化可）。
- 探索は、まず1人回しで最速キル率、妨害は後から。デッキ探索はゾーン間移動を補完し合う効果を重視し、凡庸なカードは除外。
- ループ勝利は「ループ＋ストックした回数で実際に勝つ」こと。ターンをまたぐロックも対象で、自分の山札切れ対策が必要。
- 両者同時の山札切れはターンプレイヤーの敗北。複数イベントへの置換はターンプレイヤーが先に決める（609.9a）。
