# 追記2: 通しすぎを減らす（条件を読む）、蓄積から勝ち手段を引く索引（2026-11-14）

## 9. 直したこと（`tools/loop_cond.py`、既定・日次の経路は変えない）
`engine/zone_graph` の束は日次の経路も使うので変えず、同じ形の束を条件つきで作り直した（`loop_cond.bundles`）。`fast_loop_screen.COND=True` が新しい判定。
- 条件つきの移動: 移動を囲む if（能力の if を含む）の cond を移動に付け、ループ1周の収支と組の中の札で評価する（yes / no / unknown）。no の移動は数えず、閉路の受け渡しがそれにしか頼らなければ落とす（`cond`）。unknown は落とさず、順位を下げる（読めない条件の数が少ない順）。
  - count {zone} >= n: そのゾーンへ流れ込む移動が組にあり n<=3、またはループで増える時に満たせる。<= / ==: ループで減る時。名前で数える条件は、その札がループでそのゾーンへ増える時だけ。
- 特殊勝利: 勝つ効果の条件と前提を読み、ループの蓄積で近づく時だけ勝ち手段に数える（シャコガイル: 引いた時の置換で山札1枚 → 引くループで山札が減るので yes。ケロヨン: 自分の名前の札が4体 → ループで増えないので no）。
- H.D.2.: modal の各モードの移動（相手の山札の上2枚をマナへ）と、ラスト・バーストで自分の呪文の面を唱える移動（墓地から）を読む。組の中の無償で唱えさせる常在能力があれば、閉路が手札に戻す呪文を唱えることを付け足しの効果に数える（訪れる魔の時刻が回収した H.D.2. をアカシック3で唱える）。
- 移動では満たせない限定つきの誘発（via: D・D・D などの出し方、unpaid、1ターンに1回）は閉路・付け足しに入れない。山札・盾から別のコピーを狙って出し続ける受け渡しは有限として数えない。
回帰: 既知の中核（サガ、アカシック、H.D.2. 版）は通り続け、H.D.2. 版は自身の中核（アカシック3＋訪れる魔の時刻＋H.D.2.）でも通るようになった。2枚の部分組からの3枚目の追加でも届く（`tests/test_fast_loop_screen.py`）。

# 追記3: 段1の正体と、新しい定義での段2の測り直し（2026-11-14）
