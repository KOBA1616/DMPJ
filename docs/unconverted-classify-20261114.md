## 分かったこと
- 雛形（文の形）で通る札はほとんど残っていない。変換済みの札の「1文」を辞書にして写す方法を試算しても、未変換の名前で通るのは 16 名だけ。未変換の文は1枚ごとに違う。
- 効く手は「エンジンの仕組みを足す（オーラ 92名、クロスギア系 約30名、マナの数字の変更、墓地から唱える、等）→ 該当札を LLM 変換に再投入」。
- このPRで足した雛形: ブレイクの置換（シールドを手札に加えるかわりに墓地／マナ／山札の下）。新たに通ったのは4枚（ボルメテウス3種と、原文が同じ札の写し1枚）。
