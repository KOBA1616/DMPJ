# 既知コンボの3〜4ターン勝ちの上限（2026-11-13）

測り方: `tools/ideal_draw.py`。山札の並びが見える探索（CHEAT、`search.game.play_game`、予算1000）で、通常の開幕（マナ0）から
シード 0〜39 の40通りの並び × 先攻・後攻を、自分の4ターン目まで回す。相手は無抵抗（マナチャージだけ）。macro は既定（無効）のまま。
並びを最適化したのではなく「40通りの中で都合のよい並び」を拾う近似。山札が見える最善手の勝率なので、公平な探索のキル率の**上限**として読める（ただし予算1000の探索が見つけた範囲）。

## エンジンの誤り（この測定で発見、修正済み）

超神星DOOM・ドラゲリオンの召喚コストが進化元12体以上で 0 まで下がっていた。カードは「ただし、コストは0以下にはならない」（最低1）。
`dmsim/engine/turn.py` の3か所を `max(1, ...)` に直し、`tests/test_saga_doom_route.py::test_doom_cost_never_below_one` を追加。
`cost_reduce_per_evo` を持つ札はドラゲリオンだけ。直した後も下のサガの3ターン勝ちは残った（ループ中にイザナギテラスの無償詠唱でコダマダンス・チャージャーがマナに置かれ、マナが1増えるため）。

| コンボ | 山札が見える最善手の 3〜4T 勝率 | 15% に届くか | 何が足りないか / 何があれば届くか |
