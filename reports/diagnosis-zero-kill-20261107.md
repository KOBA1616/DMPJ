# 4ターン以内キル0の診断（2026-11-07）

コードは変更していない。測定は dmsim.solitaire.play_game（CHEAT=真の山札順を見る探索、ロック判定なし、相手=T001×40の何もしない相手）を、デッキ5本×20シード×先後=40局、max_turn=8で回した結果。

## 結論
原因は**探索の予算ではない**。**「探索がターン内だけで、次ターン以降のための仕込みに評価がつかない」＋「デッキ案に入口札が無い」**が主因。変換の不備は5本のうちアカシックだけ（部品3/7が未登録）。

## 測定1: 予算（ノード数/ターン）を 200→1000→4000 に上げた
| デッキ | 4T以内キル(b=200/1000/4000) | 5T以内 | 勝ち方 |
|---|---|---|---|
| saga | 0 / 2 / 2 | 15→18→18 | ほぼ全て殴り(combat)。ループ起動(engine)は 1〜2/40 |
| tenmon | 0 / 0 / 0 | 0 | 殴り。14〜15/40 は8Tまででも勝てず |
| akashic | 0 / 0 / 0 | 8 | 殴りのみ。ノード数は369で頭打ち |
| mix_tenmon_saga | 0 / 0 / 0 | 5〜6 | 殴り |
| knight_dmc | 1 / 1 / 1 | 8〜10 | 殴り |
- 予算を20倍にしても4T以内キルはほぼ動かない（saga の2局は budget≥1000 で出る）。akashic は探索木が小さく、予算が余っている。
- 勝ちは全て殴り。ターン5〜6で相手の盾を割り切る速度で、これは「何もしない相手に素朴に殴る」基準線そのもの。**コンボは1度も狙って起動していない**（loops>0 は saga の1〜2局のみ）。よって「4T以内キル=0」は、コンボなしの殴りは5Tが最速（先攻でも）という事実どおり。

## 測定2: 逆算（キル直前局面）
data/eval/saga_near_kill.yaml（手札にドラゲリオン、墓地にサガ＋クリーチャー多数、マナ3）から始めると、budget 100/400/1600 すべて16/16局で**1ターン目に勝つ**。エンジン・変換・ループ検出・探索は、局面が揃っていれば正しく動く。
サガのキル直前に必要な局面は、loopcheck_typhoon_saga.py の結果より「ターン3開始時: 手札にサガ・ドラゲリオン(+シャコガイル/イワシン)、墓地にサガ、闇マナ2枚」。つまり最速は**3ターン目**（2ターン目に引いて捨てる札で墓地にサガを落とす）。
→ 4ターン以内は原理的に届く。届かないのは「2ターン目に墓地へサガを落とす」仕込み。

## 測定3: 入口札を足した仮デッキ
saga デッキ末尾の汎用札4枚を ET（dm26ex2-071 エマージェンシー・タイフーン）×4に替えて測定（仮デッキ、リポジトリは未変更）: 4T以内キルは b=200/1000 で 0/40、b=4000 で 2/40（いずれも殴り）。札を足しただけでは起動しない。
理由（コード読み）: TurnSearch は**自分の1ターンの中だけ**をDFSし、ターンをまたぐ計画を持たない。葉の評価（solitaire.evaluate）は盾・脅威・マナ・手札・場の枚数が中心で、「墓地にサガがある」「ドラゲリオンを手札に持つ」「闇マナ2枚」といった仕込みに点がない（goal_card は場の常在勝利条件のみ）。ETで引いて捨てる際の捨て札の選択も、評価に差が出ないので先頭のものになる。

## 原因の切り分け
| 候補 | 判定 | 根拠 |
|---|---|---|
| 探索の予算 | 主因ではない | 20倍でほぼ不変、akashic はノード数が頭打ち |
| 探索の設計(ターン内のみ、仕込みの評価なし) | **主因** | 逆算では1Tで勝つ。通しでは仕込みが起きない |
| デッキ案 | 副因 | saga に入口札(ET)が無い。tenmon は盾を作っても殴り手が足りず14/40が8Tで勝てない |
| 変換の不備 | akashic のみ | cho005 / rp3tr6 / dmrp07-009 が未登録で除外。他4本は部品が全て登録済み。キーワード中心の spell は `spell` 欄で変換済み（abilities が空でも未変換ではない） |
| 指標が粗い | 副因 | 0/1しか出ない。殴り5〜6Tが基準線で、それより速いコンボだけが数値に出る |

## 修正案（実施はしていない）
1. 【最優先】仕込み評価（セットアップ価値）: 既知コンボごとの「部品が手札/墓地/場/マナに揃った度合い」を葉の評価に加える。まず saga 用の手書き値で、ET＋saga が3T起動するか確かめる（value_fn 差し替えで dmsim/eval から試せる）。これは計画の価値V・段階指標と同じ方向。
2. 段階指標を評価ハーネスに追加（部品の到達ターン、墓地サガ有無、ループ起動回数）。0か1でなく連続値で差が見える。
3. デッキ案: build_decks に「入口・補助札（ET等）」を role: enabler で加える。tenmon は盾10枚勝ちの出口札の枚数を確認する。
4. akashic の3枚は変換を優先（変換スレッドへ）。
5. 評価の基準線として「殴りのみの5T」を明記し、コンボ起動を `origin` で必ず分けて集計する（現行の origin が使える）。
